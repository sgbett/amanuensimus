# Design exploration (archive)

Raw artefacts from a claude.ai design session (16 August 2026) exploring how the site might evolve. **Kept as record, not as fixtures** — none of this is live. The site's actual direction is in [creative-direction.md](../creative-direction.md); only a subset (the graft wordmark, the straddling credo, the paraph mark) was adopted for v1.

**Read them as sketches.** The provenance blocks inside carry *illustrative* figures — a "sgbett-2026" profile, drift numbers, model names — that are placeholders from the exploration, **not real measurements**. They are preserved unaltered on purpose: the project archives its abandoned versions rather than deleting them, and that discipline applies to its own design process.

## Contents

- `index.html` — a fuller statement page; the base for the exploration.
- `voicing-study.html` — the voicing gauge: the page rendered at four levels of voice fidelity (a study device; production would render one).
- `design-ledger.html` — design-as-amendment: the visual system as a triggered register.
- `amanuensimus-ledger.html` — the ledger plus the pigment arc (rubrication: colour withheld, arriving by amendment).
- `amanuensimus-identity.html` — the visual-identity first pass (rubrication palette, the four candidate marks).

The concepts worth keeping are reconciled and scheduled in the **v2 Roadmap** section of [creative-direction.md](../creative-direction.md) and in [../roadmap.md](../roadmap.md).
